## Quota outage, retry, and final reconciliation (2026-08-26)

**Root cause discovered:** querying the HeyGen API directly (`GET /v2/videos`) revealed that
84 of the 159 total SV/CS/TR jobs submitted across Batch 1 + Batch 2 had silently failed with
`status: "failed"`, `failure_message: "Out of monthly translation quota"`. The HeyGen web UI
never surfaced this — jobs just appeared to sit as "In line for processing" indefinitely, so
every "queued" status recorded earlier in this doc reflected UI signals, not true completion.
The outage window (all failed jobs' `created_at`) was **2026-08-19 21:22 to 2026-08-20 00:01
UTC**. Every job submitted before or after that window succeeded; the quota reset afterward.

**28 unique failed creatives** (of the 84 failed outputs, deduped by base creative — some had
1-3 of their 3 languages fail) were identified and resubmitted one at a time via direct HeyGen
video-editor URLs (`https://app.heygen.com/videos/{slug}-{id}`), using the same Precision +
Swedish/Czech/Turkish recipe as the rest of the batch. All 28 resubmissions were confirmed
queued via the "Translation" tiles appearing in each project folder.

**Retry outcome: 28/28 creatives succeeded on resubmission, zero failures.** Processing was
slow — HeyGen queued jobs sequentially rather than in parallel — taking roughly 4.5 hours from
first resubmission to the last creative (KR_TST_59_A_A2) completing. Status was polled
periodically via the API (`GET /v2/videos`, paginated, filtered by title prefix match and
recent `created_at`) and each newly-completed output downloaded immediately via
`curl -sL -o <path> <video_url>` into `~/Desktop/heygen_locales/{Swedish,Czech,Turkish}/`.
