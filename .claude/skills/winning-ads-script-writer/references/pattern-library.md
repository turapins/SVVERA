| # | pattern | tag | one-line evidence | check while writing |
|---|---|---|---|---|

## Failure modes (with the real example)

| # | failure | the example | rule |
|---|---|---|---|
| F1 | Layout swap on a proven hook | IT_TST_81_A panel: 2 purchases vs 80_A's 31, same headline | Change words or blocking, never both in one creative |
| F2 | Compliment hook | KR_TST_63_A "You 19? So deep voice" — CPA > €70 | Line 1 must cost the character something |
| F3 | Visual-only, no dialogue | IT_TST_64_C elevator shortdrama, €49.51, middling | Every hook has a spoken/captioned line |
| F4 | Recycled statistic | "93% of how you're perceived comes from how you communicate" (Mehrabian re-skin) live in two top-ten ads; "81%" in 61_C body | No percentage that is not a checkable product fact. Cut on sight. |
| F5 | Dated deadline goes stale | "By May 28th you'll thank me" ran until 7 Aug | Write relative deadlines ("in 28 days") or mark the line as re-cut monthly |
| F6 | ESL hook aimed at the US | Ivan's RW2 note on 60_A_2 | US briefs: universal pain, no accent/nationality line |
| F7 | Targeting on a thin sample | 81_A sent to Malaysia on 2 purchases | n < 10 purchases = say "LOW CONFIDENCE (n=…)", don't infer |
| F8 | Spiral rank read as conversion | c5dbf26b generic brand ad ran 14 months | Longevity = not killed. Confirm with Meta before calling it a winner |
| F9 | Brand name in the first 10 s | none of the winners; brand first spoken at 14–67 s | Product enters after the reframe |
| F10 | Lecturing the mechanism | none of the winners; competitors neither | Max two mechanism sentences, spoken by a peer |
| F11 | Two CTAs or wrong-funnel CTA | playbook loser list; not seen in winners | One CTA, matched to funnel |
| F12 | Short element tags retyped into generation prompts | script-format.md trap | Copy real IDs from Elements after import |

## How to keep this file honest (fold a new winner or loser in)

1. **Trigger.** A creative has ≥10 purchases on one account, or was killed with a stated reason, or holds a Spiral `proven_winner` band for 60+ days.
2. **Pull.** Meta row (spend, purchases, CPA, thruplay/plays, avg watch), Spiral `ad_creative_analysis` + `transcribe_ads` for the ad uuid, the script from the doc. Save under `context/winning-ads/evidence/<YYYY-MM-DD>/<CODE>/`.
3. **Classify.** Which patterns does it confirm (add to evidence column), contradict (add to counter-examples), or introduce (new row, tag by source)?
4. **Re-tag.** A pattern moves [OBSERVED]→[MEASURED] only on Vocal Image purchase data with n ≥ 10. A [MEASURED] pattern with two measured counter-examples gets demoted and flagged in chat.
5. **Update both files.** This file and METHOD.md §3/§4. Add a dated line to the refresh log below. Commit with the creative code in the message.
6. **Never** edit a pattern's tag without the evidence path next to it.
