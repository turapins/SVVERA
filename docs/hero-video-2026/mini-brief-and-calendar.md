# ЧАСТЬ 1 — МИНИ-БРИФ

## Что делаем

Два ролика из одного набора ассетов.

| | Луп на главной | YouTube-версия |
|---|---|---|
| Длина | 12 с | 60–90 с |
| Формат | 1:1 (мастер) | 16:9 |
| Звук | нет дорожки вообще | есть, дикторский |
| Склейки | 1–2, не больше | свободно |
| CTA | **не вжигаем** | вжигаем в конец |
| Задача | довести до квиза под ним | рассказать историю целиком |

Плюс третий экспорт: **9:16** из квадратного мастера для платного трафика.

## Концепция — «Сделать голос видимым»

Одна фраза: **настоящий человеческий голос, сбивчивый и с «эээ», управляет живой визуализацией — каша собирается в структуру, и структура оказывается нашим экраном результатов.**

Почему эта: продукт продаёт невидимое. Голос нельзя показать, его можно только визуализировать. Wispr Flow — голосовой продукт с той же задачей — решил её анимированным SVG с текстом реальной запинающейся речи, без единого видеофайла. Yoodli доказал, что в нашей категории геро вообще без людей работает.

**Ключевое: этой концепции не нужна генерация.** Это код (Remotion / HyperFrames), реальная аудиодорожка и записи экрана. Ни очередей, ни брака, ни проблем с консистентностью персонажа.

## Раскадровка лупа (12 с)

| Время | Что на экране | Откуда берётся |
|---|---|---|
| 0.0–2.5 | Тишина и пустая волна. Появляется первый звук — неровный, с паузой | код, аудиофайл |
| 2.5–6.0 | Волна живёт: видно запинки, «эээ», рваный ритм. Поверх — одна строка типографики | код + Катти |
| 6.0–9.0 | Хаос начинает укладываться. Волна выпрямляется в метрику | код |
| 9.0–11.0 | **Экран результатов** — полосы метрик, показатель высоты тона | запись экрана |
| 11.0–12.0 | Возврат к пустой волне. **Шов** | код |

Первый и последний кадр обязаны совпадать. Проверка простая: прокрутить двадцать раз подряд — если стык виден, не готово.

## Раскадровка YouTube-версии

| Бит | Время | Содержание |
|---|---|---|
| Хук | 0–5 с | Назвать то, в чём человек себе не признаётся: его не слушают, когда он говорит. Не про продукт, не про бренд |
| Ценность | 5–35 с | Тест голоса за 30 секунд — самый низкий порог входа, который у нас есть. Дальше *почему* работает: раскрепощение и резонанс, а не контроль |
| Доказательство | 35–65 с | Экран результатов крупно и долго. Числа на экране: **8,4 млн тестов акцента · 120+ акцентов · 96%** |
| CTA | 65–90 с | «Ready to upgrade your life? TAKE THE TEST» + возврат к первой фразе |

## Что нужно произвести

**Записи экрана — главный ассет, его нельзя сгенерировать**
- Тест голоса от начала до конца
- Экран результатов: волна, цветные полосы метрик, высота тона
- Ежедневный план
- Тест акцента
- Онбординг *(файл пока не перенесён из `~/Downloads` — macOS не даёт к нему доступ)*

Требования: нативное разрешение с реального устройства или чистого симулятора. **Не снимать телефон камерой.** Чистое состояние: без дебажных сборок, заглушек и тестовых имён. Несколько дублей каждого взаимодействия в разном темпе.

**Аудио**
- Одна реальная запись сбивчивой речи — с паузами и словами-паразитами. Это сердце концепции, вылизанная дикторская начитка её убьёт
- Дикторский голос для YouTube-версии (ElevenLabs)

**От Катти**
- Типографическая система, цвет
- Дизайн CTA-карточки
- Анимация логотипа

**Генерация — только если понадобится**
Окружение, текстуры, абстракция. **Синтетического ведущего в кадре не делаем** — для продукта, который обещает живой человеческий голос, сгенерированная говорящая голова это прямой удар по доверию.

## Технические требования

**Луп**
```
1:1, 12 с, AV1 основной + H.264 запасной
до 4 МБ, CRF 23–28
аудиодорожки нет вообще
poster-кадр из первого кадра — он же LCP-элемент страницы
```

**YouTube**
```
16:9 1920×1080, H.264 + AAC
звук есть, субтитры вжиты
CTA-карточка в конце
```

**9:16** — 1080×1920 из квадратного мастера, субтитры, один CTA.

Композицию строим **1:1 с наложенной safe-зоной 9:16**, чтобы вертикаль получалась бесплатно, а не спасалась перекадровкой потом.

## CTA

**В YouTube-версию вжигаем.** Там есть настоящий финал, карточка держится 3–4 секунды.

**В луп — нет.** У лупа нет конца: плашка в последние 3 секунды двенадцатисекундного лупа это пятая часть цикла, и половина людей увидит призыв раньше продукта. Под видео фраза живёт живым HTML с кнопкой на квиз:

> **Ready to upgrade your life?**
> [ TAKE THE TEST ]

## Чего делать нельзя

- Мутный тёмный грейд с тяжёлой виньеткой — этим испорчен нынешний ролик
- Первый кадр как расфокусированная пустая комната — это будет poster
- Держать один кадр 19 секунд, как в старом файле
- Снимать экран телефона камерой вместо записи экрана
- Синтетический ведущий
- Числа без проверки — всё непроверенное помечаем `{VERIFY}` и вырезаем

## Приёмки

Три штуки, все с закрывающимся сроком.

| | Что смотрим | Правило |
|---|---|---|
| **1** | Раскадровка и сценарий, до того как что-то собрано | Закрывается в конце дня |
| **2** | Черновой монтаж обоих роликов | Правки только с таймкодом. Закрывается через сутки |
| **3** | Чистовой | **Только подтверждение.** Новое направление здесь = сдвиг даты, и это решение Ивана вслух |

Правила, которые держат процесс: одна ветка обсуждения, не личка · без таймкода правка не считается · молчание к сроку = согласие · закрытый круг не открывается заново.

## Что можно начинать не дожидаясь ничего

**Запись экрана.** Она не зависит от выбора направления — экран результатов нужен всем трём. Это самый важный ассет, единственный, который нельзя сгенерировать, и единственный, который конкуренты не скопируют. Если делать что-то сегодня — то это.
